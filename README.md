## 📺 Що нового у версії v3.4 PRO

1. **⚡ Пряме програвання торрентів онлайн всередині додатку (P2P Streaming Engine)**:
   - Інтегровано повнофункціональний торрент-стрімер на базі Webtor: будь-який знайдений торент із торент-трекерів (`ThePirateBay`, `YTS`, `EZTV`, `Hurtom`) тепер можна дивитися онлайн без необхідності попереднього завантаження гігабайтів файлів на диск!
   - Підтримка вибору звукових доріжок, вбудованих субтитрів, перемотування та повного спектру роздільних здатностей (від 1080p до нестисненого 4K HDR).
   - Швидкий доступ до торент-потоків безпосередньо з панелі плеєра (`⚡ Торренти`) та з вкладки торентів у картці фільму.

2. **🔊 Панель вибору озвучення та якості для пультів ДК і мишок**:
   - Вирішено проблему недосяжності налаштувань у плеєрі для телевізійних пультів: додано великі, виділені кнопки **«Озвучення»** та **«Якість»** прямо на верхній панелі керування плеєра.
   - Зручне спливаюче меню зі швидким вибором:
     - 🇺🇦 **Ashdi UA** — повний український дубляж (UAKino)
     - 🎭 **HDRezka Multi** — багатоголосе озвучення з вибором студій
     - 💎 **VidLink 4K** — максимальна якість Ultra HD для великих екранів
     - 🌐 **VidSrc PRO** — мультиязичний оригінальний потік
     - ⚡ **P2P Торренти** — чистий потік без перекодування
   - Гарячі клавіші на пульті/клавіатурі: `A` — Озвучення, `Q` — Якість, `T` — Торренти, `ESC` — Закрити меню/плеєр.

3. **🎯 100% сумісність з мишками та пультами-указками (Air Mouse / Гіроскоп)**:
   - Виправлено обробку кліків у стрічках фільмів: усунено помилкове блокування кліку при мікро-тремтінні курсора гіроскопічної указки. Тепер будь-яка кнопка чи фільм чіпляються мишкою миттєво з першого дотику!
   - Інтелектуальний Drag-to-Scroll: розрізняє навмисне плавне перетягування горизонтальних стрічок та звичайний клік по картці.
   - Збільшені тач-зони для впевненого керування з великої відстані.

4. **🚀 60 FPS та надлегка оптимізація для проєкторів і бюджетних Smart TV**:
   - Повністю вимкнено важкі графічні фільтри `backdrop-filter: blur`, які перевантажували графічні чіпи Mali/PowerVR на проекторах і телевізорах та викликали падіння FPS.
   - Увімкнено апаратне прискорення рівня WebView (`LAYER_TYPE_HARDWARE`), високий пріоритет рендерингу та оффскрін-прерастеризацію у нативному шарі Android.
   - Інтерфейс літає плавно, без підвисань та нагріву пристрою.

5. **📱 Адаптивна мобільна картка фільму (Fluid Bottom Sheet)**:
   - Картка фільму на смартфонах тепер розгортається на повну комфортну висоту (`94dvh`) зі зручним індикатором свайпу.
   - Додано плавні скелетони завантаження опису, завдяки чому інтерфейс не смикається під час підтягування метаданих з IMDb та TMDB.
   - Зручна навігація між серіями, серверами та торентами в один клік.

## 🛠️ Розробка та збірка з вихідного коду

```bash
# 1. Встановлення залежностей
npm install

# 2. Запуск локального сервера розробки
npm run dev

# 3. Збірка веб-частини та синхронізація з Android
npm run cap:sync

# 4. Компіляція готового APK (потрібен JDK 21)
cmd /c "set JAVA_HOME=C:\Users\zod4ix\jdk-21.0.6+7&& set PATH=C:\Users\zod4ix\jdk-21.0.6+7\bin;%PATH%&& cd android && gradlew.bat assembleDebug"
```
