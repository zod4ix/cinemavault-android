# 🎬 CinemaVault PRO v3.3 (Smart TV & Universal Edition)

> **Автономний мультиплатформний онлайн-кінотеатр «для своїх»**: оптимізований під **Smart TV (Android TV / Google TV / TV-бокси / проектори)**, пульти дистанційного керування (D-Pad), **пульти-указки (Air Mouse / гіроскоп)**, звичайні комп'ютерні миші та сенсорні екрани смартфонів і планшетів. ## 📺 Що нового у версії v3.3 PRO (Smart TV & Universal Edition)

1. **🎮 Повна адаптація під Smart TV (Android TV / Google TV / Android 9-16)**:
   - Додано маніфест-декларації `LEANBACK_LAUNCHER` та `android.hardware.touchscreen = false`, що дозволяє встановлювати й запускати додаток на будь-яких телевізорах, ТВ-приставках і проекторах.
   - Підтримка офіційного телевізійного банера 16:9 для головного меню Android TV.
   - **10-foot UI & Overscan Safe-Area**: інтелектуальні відступи по краях екрана, що захищають інтерфейс від обрізання на телевізорах із увімкненим Overscan.
   - Адаптивна сітка фільмів: масштабується до 7–8 колонок на великих екранах 1080p, 2K та 4K HDR.

2. **🎯 Підтримка пультів-указок (Air Mouse / Magic Remote) та USB-мишок**:
   - **Drag-to-Scroll (перетягування мишкою)**: тепер будь-яку горизонтальну стрічку фільмів (`MediaRow`), сезонів або серверів можна плавно скролити, затиснувши ліву кнопку миші/указки й потягнувши вбік.
   - **Трансляція коліщатка миші**: прокручування колеса автоматично гортає горизонтальні стрічки.
   - Збільшені зони кліку (мінімум 44px) для комфортного натискання навіть при тремтінні курсора гіроскопічної указки.
   - Візуальні навігаційні кнопки-стрілки зі швидким посторінковим гортанням каталогу.

3. **🕹️ Навігація штатними кнопками пульта ДК (D-Pad / Arrows)**:
   - Усі картки фільмів, кнопки плеєра, фільтри та категорії підтримують фокус із клавіатури та пульта (`Стрілки`, `OK / Enter`, `Back / Назад`).
   - Яскравий червоний неоновий контур фокуса (`:focus-visible`), який чудово видно з відстані 3–4 метрів.
   - **Автоцентрування фокуса**: при переході стрілками обраний фільм автоматично плавно центрується на екрані.

4. **🍿 Розумний відеоплеєр із OSD та гарячими клавішами ТБ**:
   - Обробка нативних мультимедійних кнопок пульта: `Play/Pause`, `Швидке перемотування (+10с / -10с)`, `Попередня/Наступна серія`, `Гучність`, `Mute`, `Стоп`.
   - Інформаційний **OSD (On-Screen Display)** бейдж на екрані (`⏪ -10 сек`, `⏩ +10 сек`, `▶ Відтворення`, `⏸ Пауза`, `🔊 85%`).
   - Кнопка швидкого перемикання на резервний сервер без переривання перегляду.

5. **⚡ 7 серверів відтворення + Вбудований AdBlock**:
   - **VidSrc PRO (1080p Global)** — стабільний запуск за `IMDb ID` без обмежень.
   - **UA / HDRezka Multi (`Kinobox`)** — український дубляж (`Ashdi`, `DniproFilm`, `Цікава Ідея`, `HDRezka Studio`, `Kodik`, `Alloha`).
   - **VidLink 4K HDR**, **AutoEmbed**, **VidSrc Mirror**, **SuperEmbed** — резервні сервери.
   - **YouTube 4K Трейлери + Нативний HLS (`.m3u8` / `.mp4`)** із можливістю підключення власного потоку (наприклад, `TorrServe`).
   - Вбудований захист від спливаючої реклами у WebView.

6. **🔍 5-рівневий живий глобальний пошук**:
   - Працює через нативний Android HTTP (`CapacitorHttp`) без CORS.
   - Пошук 5 мовами (українська, англійська, польська, іспанська, тощо).
   - Бази: IMDb Suggestions, Wikidata UA, TVMaze, Jikan Anime, iTunes.

## 🛠️ Розробка та збірка з вихідного коду

```bash
# 1. Встановлення залежностей
npm install

# 2. Запуск локального сервера розробки
npm run dev

# 3. Збірка веб-частини та синхронізація з Android
npm run cap:sync

# 4. Компіляція готового APK (потрібен JDK 21)
cd android && gradlew.bat assembleDebug
```
