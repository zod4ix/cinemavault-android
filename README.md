## 🔥 Що нового у версії v3.6.1 PRO

0. **📽️ Ідеальна робота мишки, пульта та клавіатури на проєкторах, Smart TV та всіх девайсах + Наскрізний комбайн керування плеєром (v3.6.1)**:
   - **Виправлено проблему «мишка бігає верхнім шаром і не натискає кнопки» на проєкторах (`MainActivity.java`)**: перехід на Window-local координати (`getLocationInWindow`) повністю усунув зміщення кліків через 4-точкову трапецеїдальну корекцію (Keystone) та цифровий зум проєкторів, а збереження нативного `SOURCE_MOUSE` у Chromium WebView із каскадом `__cinemaEnsureClickAt` + `dispatchAsyncFingerTapToWebView` забезпечує 100% спрацьовування кожної кнопки додатку та плеєра.
   - **Універсальна нижня док-панель прокрутки (SeekBar) та керування для ВСІХ серверів (Rezka, Ashdi, Videasy, VidLink, HLS, Торренти)**: тепер при натисканні стрілки **«Вниз»** на пульті з верхньої панелі серверів фокус миттєво перестрибує на **шкалу прокрутки таймлайну (`Прокрутка: ◀ / ▶ на пульті або клік мишкою`)** та нижній пульт керування (`Пауза`, `-15с / +15с`, `-1хв / +1хв`, `Звук`, `Озвучення`, `Якість 4K/1080p/720p/480p`, `Підсилювач звуку 300%`, `Формат екрана`, `⚙️ Налаштування`).
   - **Наскрізний міст всередину iframe-плеєрів (`WebViewCompat.addDocumentStartJavaScript` Subframe Bridge)**: кліки мишкою, віртуальним курсором та команди пульта (`Прокрутка`, `Зміна мови/озвучення`, `Якість`, `Налаштування шестерні`) напряму передаються всередину вбудованих плеєрів (зокрема Rezka / PlayerJS / Ashdi / Kodik / Videasy / VidLink).

## 🛠️ Розробка та збірка з вихідного коду

```bash
# 1. Встановлення залежностей
npm install

# 2. Запуск локального сервера розробки
npm run dev

# 3. Збірка веб-частини та синхронізація з Android
npm run cap:sync

# 4. Компіляція підписаного Release APK (потрібен JDK 21)
cmd /c "set JAVA_HOME=C:\Users\zod4ix\jdk-21.0.6+7&& set PATH=C:\Users\zod4ix\jdk-21.0.6+7\bin;%PATH%&& cd android && gradlew.bat assembleRelease"
```
