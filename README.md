## 🔥 Що нового у версії v3.6.3 PRO

0. **⏸ Відновлено залізну паузу та додано YouTube-прокрутку (v3.6.3)**:
   - **Відновлено роботу паузи**: усунуто блокування та хибну прокрутку при спробі поставити на паузу. Пауза та пуск тепер працюють безвідмовно на всіх типах серверів (Ashdi, Rezka, Videasy, HLS, Webtor) через подвійний каскад команд `play`/`pause` + `togglePlay` та натискання внутрішніх елементів керування.
   - **Прибрано зайві кнопки +15с / -15с**: кнопки прибрано з нижньої док-панелі для забезпечення чистого, просторого інтерфейсу та уникнення випадкових натискань.
   - **Прокрутка подвійним дотиком (Double Tap) як у YouTube**:
     - Подвійний дотик/клік по **лівому краю (30%)** екрана — миттєва перемотка на **-15 секунд** з анімованим бейджем `⏪ 15 сек`.
     - Подвійний дотик/клік по **правому краю (30%)** екрана — перемотка вперед на **+15 секунд** з анімованим бейджем `⏩ 15 сек`.
     - Подвійний дотик по **центру** — моментальне перемикання **Пауза / Пуск**.

1. **🇺🇦 Залізний вибір української озвучки та усунення закриття вікна налаштувань**:
   - **Кнопки мов тепер реально перемикають аудіо**: натискання на кнопку `[🇺🇦 Українська]` у меню відтепер безпосередньо вмикає найкращий український сервер (Ashdi / КіноБаза UA) та активує український дубляж, а не лише фільтрує список. Аналогічно кнопки `[🇬🇧 English]`, `[🇵🇱 Polski]`, `[🇪🇸 Español]` миттєво застосовують відповідні аудіодоріжки.
   - **Усунуто миттєве закриття внутрішніх меню плеєра**: виправлено помилку дублювання кліків (`triggerSmartClickAtWindowCoords` більше не надсилає паразитичні кліки для сенсорного введення, а `fireFullTapOnElement` усунув подвійний `click`). Тепер меню «Настройки -> Озвучка -> HDRezka Studio / Дубляж» не закривається самовільно й дає змогу вільно обрати будь-яку студію перекладу!
   - **Пріоритет UAKino / Ashdi**: сервер з оригінальним українським дубляжем встановлюється за замовчуванням під час завантаження фільму.

2. **🛡️ Безпечне та тихе оновлення без попереджень Android (Play Protect Safe)**:
   - Додано схему підпису **APK Signature Scheme v3** на додачу до v1 та v2, сумісність із **Android 15 (Target SDK 35)** та офіційний **Network Security Config** (`network_security_config.xml`).
   - Збережено оригінальний цифровий підпис релізу (`CB:92:93`) для безшовного та безпечного оновлення поверх будь-якої попередньої версії без попереджень про небезпечне походження.

1. **🏟️ Окремий комбайн «🔴 Спорт Live» (`SportsHub` — Free Live Stream Scanner)**:
   - Виділена сторінка живих спортивних трансляцій, розкладу матчів, свіжих хайлайтів та повних записів матчів (за архітектурою сканера `vinegret.net/nba-na-vinegret/`): **НБА (NBA), Ліга Чемпіонів УЄФА, АПЛ, Ла Ліга, Серія А, Бундесліга, НФЛ (NFL & RedZone), Формула 1, Бокс / UFC / MMA, Теніс ATP/WTA, НХЛ (NHL)**.
   - **5-рівневий каскад безкоштовних потоків «До переможного» (`Потік A / B / C / D / E`)**: кожна подія автоматично отримує `Потік A (Live 1080p FHD StreamFree)`, `Потік B (Резервний Live 540p)`, `Потік C (Direct HLS .m3u8 з Hls.js)`, `Потік D (Свіжі офіційні хайлайти HD)` та `Потік E (Повний запис матчу)`. Жодних платних підписок чи мовних блокувань — 100% безкоштовні робочі потоки!
   - **12 безкоштовних спортивних арен-каналів 24/7**: `NBA Live Court & NBA TV`, `Champions League & Top Football`, `beIN SPORTS XTRA & FIFA+`, `NFL RedZone & Fox Sports 1`, `Sky Sports F1 & Motorsport`, `UFC / FightBox HD & Glory`, `Sky Sports Tennis & Eurosport`, `NHL Ice Arena` тощо.

2. **🇺🇦 Мультимовні канали (Українські першими + усі мови додатку)**:
   - Розширено сітку онлайн-серверів до **14+ незалежних каналів**:
     - Першими завжди йдуть **4 українські канали**: `🇺🇦 UA • Ashdi (UAKino)`, `🇺🇦 UA • КіноБаза / Kodik`, `🇺🇦 UA • Videasy 4K Українська`, `🇺🇦 UA • AutoEmbed Українська`.
     - Потім — канали усіма мовами інтерфейсу додатку: `🇬🇧 EN • VidLink 4K`, `🇬🇧 EN • VidSrc PRO`, `🇵🇱 PL • Videasy Polska`, `🇪🇸 ES • Videasy Español`, `🎭 Rezka Multi`, `🌐 Videasy Global 4K`, `VidSrc PM/ME/SU`, `2Embed`.
   - Додано швидкі фільтри мов (`Усі`, `🇺🇦 UA`, `🇬🇧 EN`, `🇵🇱 PL`, `🇪🇸 ES`, `💎 4K`, `🌐 MULTI`) прямо у картці фільму та у верхній панелі відеоплеєра.

3. **⚡ Прокачаний P2P Торрент-плеєр (Torrentio + TPB + YTS + EZTV)**:
   - Підключено мульти-індексатор **Torrentio (Stremio API)** разом із паралельним мультимовним пошуком по `ThePirateBay`, `YTS` та `EZTV`.
   - Автоматичний пріоритет релізів з українською доріжкою (`🇺🇦 UA` — Toloka / Hurtom / UAFix / Baza / DniproFilm) та миттєве підключення WebRTC (`wss://`) і 15 швидкісних UDP-трекерів для стабільного стрімінгу без гальмувань.

4. **♾️ Нескінченна бібліотека контенту та «🏛️ Золота класика»**:
   - Додано категорію та стрічку **«🏛️ Золота класика»** (легендарні шедеври кіно, мультфільми та аніме до 2012 року) поруч зі стрічкою **«🔥 Свіжі новинки 2024–2026»**.
   - Реалізовано **Infinite Scroll (`IntersectionObserver`)**: при прокручуванні вниз додаток автоматично підвантажує нові сторінки каталогу з різних епох і жанрів без лімітів.

5. **🛡️ Самовідновлення (`Self-Healing Engine`) та GitHub Auto-Updater**:
   - Автоматичне перехоплення помилок рендерингу та мережі, валідація `localStorage`, відновлення профілю з резервного сховища `IndexedDB` та очищення битих кешів без втрати даних користувача.
   - Автоматична перевірка нових релізів на GitHub (`zod4ix/cinemavault-android`) зі сповіщенням, QR-кодом для Smart TV та прямим завантаженням `.APK`.

6. **☁️ Крос-девайс Хмарна Синхронізація та Бекап**:
   - Детермінована генерація коду профілю `CV-XXXXXX` за `Email + PIN` (однаковий код на всіх ваших пристроях), миттєва синхронізація через хмарний релей `ntfy.sh` + `restful-api.dev` + `IndexedDB`, а також експорт/імпорт `.JSON` файлу профілю.

7. **🎯 Ідеальна геометрія без перекриття та 2D Spatial Navigation для пультів**:
   - Повністю перероблена архітектура шапки, бейджів карток та банерів — жодна кнопка не перекриває інший елемент на жодній мові чи роздільній здатності.
   - Розумна 2D-навігація стрілками пульта (`ArrowUp/Down/Left/Right`) по всіх елементах інтерфейсу.

## 🛠️ Розробка та збірка з вихідного коду

```bash
# 1. Встановлення залежностей
npm install

# 2. Запуск локального сервера розробки
npm run dev

# 3. Збірка веб-частини та синхронізація з Android
npm run cap:sync

# 4. Компіляція підписаного Release APK (потрібен JDK 21)
cmd /c "set JAVA_HOME=C:\Users\zod4ix\jdk-21.0.6+7&& set PATH=C:\Users\zod4ix\jdk-21.0.6+7\bin;%PATH%&& cd android && gradlew.bat assembleRelease"
```
